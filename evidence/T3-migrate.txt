MIGRATION PROCEDURE
  Old shape -> new shape via SQLite standard rebuild (UNIQUE/PK cannot be ALTERed):
  PRAGMA foreign_keys=OFF (outside tx — no-op inside); BEGIN;
  CREATE <t>_new (new DDL); INSERT INTO <t>_new SELECT <cols>, 'sol' FROM <t>;
  DROP TABLE <t>; ALTER TABLE <t>_new RENAME TO <t>;  (x3 tables)
  CREATE INDEX idx_trades_ca; COMMIT; PRAGMA foreign_keys=ON; PRAGMA foreign_key_check.
  Idempotent: trigger = wallet_token_state.chain absent -> fresh DB and 2nd open no-op.
  Runs AFTER the token_amount/source/clan ALTER migrations so all columns exist to copy.
