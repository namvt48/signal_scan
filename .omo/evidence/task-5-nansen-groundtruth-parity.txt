== OBJECTION (D6 step 2) — logged per spec, implemented as specified ==
TRANSFER_FALSE_POSITIVE checks the literal `events` argument (all mints), while
every metric uses `evs` filtered to group.ca (D2). In a sig where a
transfer-only group for ca=X coexists with a swap for ca=Y, the literal check
can raise a false TRANSFER_FALSE_POSITIVE for X. Measured C2 case (1bPapYy2…)
gives TFP under BOTH readings, so the current gate is unaffected. Noted in the
classify docstring; part 2 / todo 6 decides what to pass.

== SPEC DEVIATION (test 8 threshold) ==

(truth buy 48930.78620605, truth fee-sell 48.9307862, ev qty_net 48930.786206
and 48.930786) the exact value is 3.0686e-12 (fee qty rounded to 6 decimals

writing the test. Test asserts `net_rel < 1e-11` — still ~1e4× tighter than
NET_CAP 0.015 and proves the identity holds. All other test-8 numbers match
spec exactly (net_owner_delta 0.0, fee_usd_ratios[0] 0.90399 ≈ 0.904 ±0.01,
