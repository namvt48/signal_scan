## Design implemented

Amendment C0 rejected the original condition `(b) role(dst) != "POOL"` because 9/9 real fee collectors have balance-derived `rd=POOL`.

Implemented B1 instead:

- `(a)` capture only rejected legs with `role(src) == "WALLET"`
- capture reasons limited to:
  - `aggregator_frame`
  - `plumbing`
  - `no_pool_endpoint`
- `(b)` B1: candidate `dst` and `dst_owner` must not be any pool account/pool owner referenced by paired swap steps in the same tx
- `(c)` candidate mint must have at least one BUY step with the same base mint in the same tx
- nearest BUY step selected by `|Δseq|`, tie-break by seq, matching `_match_pairs`
- fee event inherits `quote_mint`, `quote_sym`, `unit_price`, `quote_inferred`, `symbol_pending` from selected BUY event
- fee event uses:
  - `side="SELL"`
  - `type="SWAP"`
  - `fee_leg=True`
  - `pool=""`
  - `amount_basis="gross_leg"`
  - `qty=qty_net=gross fee amount`
  - `quote_qty=qty × inherited unit_price`
  - `quote_usd=quote_qty × existing cache price path`
- regular events for the fee mint receive adjusted net:
  - `net_adj[mint] = net_owner[mint] + Σ promoted fee_out[mint]`
- regular and fee events are sorted together by sequence key, then `step`/`n_steps` are renumbered as one batch.

Code additions:

- `_FEE_REJECT_REASONS`
- `_fee_candidate(...)`
- `_legs_with_roles(tx, wallet, trace=None, rejected=None)` optional side-channel parameter
- capture calls at the three allowed reject sites
- `_quote_px(...)`
- `_symbol_pending(...)`
- `_fee_event(...)`
- `_promote_fee_candidates(...)`
- `detect_swaps` fee promotion, net adjustment, combined ordering, `FEE` trace line

## Risks / deliberate limits

- B1 is tx-local. If a real fee collector is also a pool account/pool owner of an unrelated paired step in the same tx, it is conservatively not promoted. This prevents the C7 false positive.
- Candidate capture is limited to `aggregator_frame`, `plumbing`, and `no_pool_endpoint`. Legs rejected later as `same_mint` or `unpaired` are intentionally not fee candidates, preserving `C7b` and existing pAMM behavior.
- Fee quote/unit_price are inherited from the nearest same-mint BUY event. If that BUY event were absent, the fee is skipped.
- Fee events participate in `step`/`n_steps` numbering, so downstream text traces may show higher `n_steps` for txs with promoted fee legs. All required regression suites pass.
- `ruleA_real_regress.py` still fails by design because `/opt/wallet-watch/wallet_watch.py` is absent in this workspace.
